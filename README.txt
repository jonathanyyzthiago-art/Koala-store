KOALA STORE

1. Coloque estes arquivos no mesmo diretório do seu GitHub Pages:
   index.html
   style.css
   app.js

2. Coloque também logo.jpg se quiser usar seu logo.

3. A página já tem:
- busca central no topo antes de Entrar;
- banner primeiro;
- categorias Assinaturas e Jogos depois do banner;
- área de arrastar/clicar para imagens do banner, categorias e produtos;
- comprar adiciona ao carrinho;
- carrinho e área de compra;
- login;
- Discord e Instagram no rodapé;
- suporte quadrado;
- neve;
- animações de entrada e botões 3D.

IMPORTANTE SOBRE AS IMAGENS:
As imagens colocadas por arrastar/clicar são salvas no localStorage do navegador. Isso permite editar sem painel e sem mexer no código, mas a imagem não é enviada automaticamente para o GitHub. Para que a imagem apareça para TODOS os visitantes do domínio, será necessário ligar essas áreas a um armazenamento (por exemplo, Supabase Storage) ou a uma automação do GitHub.
