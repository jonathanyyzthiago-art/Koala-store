KOALA STORE - GITHUB PAGES

1. Envie todos os arquivos desta pasta para a raiz do seu repositório GitHub Pages.
2. O arquivo principal obrigatoriamente deve se chamar index.html.
3. Não altere os nomes index.html, style.css e app.js.
4. Abra a URL do GitHub Pages normalmente.

IMAGENS
As caixas pontilhadas são áreas de arrastar e soltar. Também é possível clicar nelas para escolher uma imagem.
As imagens ficam salvas no navegador usando localStorage nesta versão estática. Para que as imagens fiquem disponíveis para todos os visitantes, será necessário ligar essas áreas ao Supabase Storage.
