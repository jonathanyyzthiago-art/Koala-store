# Koala Store

Projeto estático para GitHub Pages.

## Imagens permanentes
- `products/discord-category.jpg` — imagem da categoria Discord na home.
- `products/nitro-discord.jpg` — imagem do Nitro Discord e banner da página Discord.
- `products/texturas-minecraft.jpg` — imagem de Texturas de Minecraft e categoria Jogos.
- `products/assinaturas.jpg` — imagem de Assinaturas e categoria Assinaturas.

O `index.html` carrega `product-images.js` antes de `app.js`, e todas as imagens do catálogo usam `PRODUCT_IMAGES`.
