# Koala Store

Projeto estático preparado para GitHub Pages.

- `products/discord-category.jpg` — 1ª imagem enviada: arte da categoria Discord.
- `products/texturas-minecraft.jpg` — 2ª imagem enviada: produto Texturas de Minecraft e categoria Jogos.

## Configuração

As imagens dos produtos são controladas por `product-images.js` e usadas pelo `app.js`.
Todos os caminhos das imagens são relativos, sem caminhos do computador local.
