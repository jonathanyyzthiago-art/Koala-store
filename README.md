# Koala Store

Todas as imagens do site estão embutidas diretamente em `product-images.js` como Data URLs.
O projeto não depende de arquivos de imagem externos, CDN, upload ou caminhos do computador.

Arquivos:
- `index.html`
- `style.css`
- `app.js`
- `product-images.js`

O GitHub Pages precisa apenas desses arquivos para carregar as imagens.
